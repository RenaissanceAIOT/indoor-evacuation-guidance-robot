## 3. 指标计算

### 导航成功率

```text
success_rate = 成功到达且无人工接管的任务数 / 总任务数
```

必须同时报告总任务数、超时定义、人工接管次数和碰撞次数，不能只报告成功样本。

### 终点误差

使用地面标记或外部测量，计算机器人 `base_link` 实际终点到目标点的二维距离。报告均值、中位数、P95 和最大值。

### 感知指标

按视频段划分训练/验证数据，避免相邻帧泄漏。人员检测至少报告 Precision、Recall 和误检场景；深度定位报告不同距离区间的中位绝对误差。
