# 从实验室研究方向到未来应用系统

## 1. 研究出发点

实验室既有工作关注自主移动、室内感知、路径规划、人机交互和紧急疏散。论文或单项实验通常验证一个明确问题，例如定位精度、避障策略或人员识别；未来应用则要求这些能力在同一台机器人上持续协作，并能够解释失败、进入安全状态和保存实验证据。

本项目研究的不是重新发明每个算法，而是解决“研究模块如何成为系统”的问题。

## 2. 研究能力与工程模块映射

| 研究方向 | 工程化问题 | 本项目实现 |
| --- | --- | --- |
| 室内 SLAM | 地图能否复用、坐标是否连续 | SLAM Toolbox、AMCL、标准 TF 树 |
| 路径规划 | 全向底盘与动态行人如何处理 | SmacPlanner2D、DWB、动态代价地图 |
| 视觉识别 | 二维检测如何进入机器人坐标 | RGB-D 同步、深度中值、三维反投影 |
| 人机交互 | 人员如何理解机器人意图 | 灯光、蜂鸣器、机体朝向和手势接口 |
| 智能疏散 | 出口失效时如何重新决策 | 风险加权出口选择与任务状态机 |
| 系统可靠性 | 模块失败后是否继续盲目运行 | 看门狗、health、FAULT/BLOCKED、任务日志 |

## 3. 应用研究假设

1. 移动引导能够把实时路径信息带到人员所在位置；
2. 全向底盘在走廊会车和狭窄区域具有机动优势；
3. 静态最短路径不足以表示风险，出口选择需要同时考虑距离、通道状态和人群密度；
4. 机器人意图必须通过多模态提示持续表达；
5. 任何单点感知结果都不应直接触发高风险动作；
6. 可落地研究必须保留日志、失败样本和复现实验配置。

## 4. 可验证研究问题

- 不同风险权重对出口选择稳定性的影响；
- 麦克纳姆横向运动对走廊通行时间与定位漂移的影响；
- 静态指示、灯光、声音和机器人运动组合对人员理解速度的影响；
- 动态障碍密度对 Nav2 规划恢复率的影响；
- 视觉推理负载对导航控制周期和主控温度的影响；
- 任务日志能否降低故障定位时间。

## 5. 研究与应用边界

仓库实现的是未来应用研究平台：它可以在受控楼宇环境中验证导航、引导和系统行为，但不能等同于经过认证的消防设备。真实试点还需要建筑事件系统、网络安全、隐私保护、物理停止装置、耐环境设计和法规审查。
